# 长安大学选课辅助筛选脚本

这是一个给长安大学本科教务系统用的选课辅助脚本。它主要解决学校选课页面筛选条件太少的问题，帮你更快看出哪些课和自己的课表不冲突、哪些课符合考试方式、授课语言、先修课程等条件。

它不是抢课脚本，也不会帮你自动点击“选课”。

## 能做什么

- 自动在教务系统选课页面上方加入“选课辅助筛选”工具栏。
- 根据你的真实课表判断候选课程是否时间冲突。
- 支持筛选：
  - 时间无冲突
  - 早八友好课表，也就是筛掉第 1-2 节的课
  - 有余量
  - 无先修课程
  - 考试方式：考查 / 考试
  - 授课语言：中文 / 双语
  - 教学楼位置：WX / WM / WH / WT / 其他
  - 只看匹配
- 点击候选课程行后，会在上方课表里高亮这门课对应时间。
- 可以后台读取完整课表，用真实教学周判断冲突，减少学校缩略课表造成的误判。
- 可以低频读取课程详情，用来判断先修课程、考试方式、授课语言等信息。

## 安装方法

1. 在 Edge 或 Chrome 浏览器安装 Tampermonkey。
2. 打开 Tampermonkey，新建一个用户脚本。
3. 把 `chd-course-helper.user.js` 里的全部内容复制进去。
4. 保存脚本。
5. 打开学校教务系统，正常用自己的账号密码登录。
6. 进入选课页面，看到“选课辅助筛选”工具栏就说明安装成功。

如果要发给同学，可以直接发 `release` 文件夹里的 `chd-course-helper.user.js` 和 `安装说明.md`。

## 推荐使用方法

1. 进入选课页面。
2. 如果页面已经能正常判断冲突，可以直接使用。
3. 如果担心缩略课表误判，点一次“后台读取课表”。
4. 浏览器可能会打开一个新的课表页，读取完成后会自动关闭。
5. 勾选自己想要的筛选条件，比如“时间无冲突”“早八友好课表”“教学楼位置”“无先修课程”等。
6. 如果勾选了考试方式、授课语言、无先修课程，脚本会低频读取匹配课程的详情。
7. 如果不想继续读取详情，点“停止详情读取”。
8. 切换课程列表页后，脚本会尽量自动按当前条件重新筛选。

## 按钮说明

- `读取/刷新`：重新读取当前页面课程列表，并按当前条件筛选。
- `后台读取课表`：打开一个单独课表页，读取完整课表后自动关闭。
- `读取匹配详情`：低频读取当前页时间无冲突课程的详情。
- `停止详情读取`：停止正在进行的详情读取。
- `缓存当前详情`：如果你手动打开了某门课详情页，可以点这个按钮缓存该课程详情。

## 使用提醒

- 第一次使用时，建议先点一次“后台读取课表”。
- 如果某门课显示“详情未知”，说明脚本还没读到这门课的详情。
- 如果详情读取很慢，是正常的。脚本刻意降低访问频率，避免对学校网站造成压力。
- 如果同一台电脑换了别人登录，建议刷新页面后重新点一次“后台读取课表”。
- 如果学校教务系统改版，脚本可能需要更新。

## 安全说明

- 脚本不会保存、读取或上传你的学号密码。
- 登录只发生在学校官方教务系统页面。
- 脚本不会自动点击“选课”按钮。
- 脚本不会高频循环访问网站。
- 读取到的课表和课程详情只保存在当前浏览器本地。
